# 작업 기록 - Android에서 G435 전원·마이크 버튼 신호 확인(HCI snoop)

- 기록 일시: 2026-11-01 16:05 (Asia/Seoul)
- 실제 작업 시각: 2026-11-01 14:53–16:01 (logcat·btsnoop 시각)
- 작성자/에이전트: Claude
- 작업 유형: 진단

## 요약

다음/이전 곡 입력으로 쓸 수 있는지 보려고 재생 중 G435 전원·마이크 버튼을 짧게 눌렀다. 두 버튼 모두 폰으로 보내는 Bluetooth 패킷이 없었다(HCI snoop로 확인). 폰이 받는 G435 입력은 +/−의 AVRCP 절대 볼륨뿐이므로 다음/이전 곡도 +/− 조합으로 만들어야 한다.

## 변경 범위와 주요 파일

- 코드 변경 없음. 이 보고서와 `docs/03-product-plan.md`, 루트 `README.md` 이력, `.claude/session-handoff.md`만 갱신했다.
- 원본(logcat, bugreport, `btsnoop_hci.log`)은 Bluetooth 주소·기기 정보가 있어 저장소에 넣지 않았다.

## 관측과 검증

기기: SM-S916N / Android 16, Bluetooth(A2DP·AVRCP·HFP), Spotify 재생 중. HCI snoop은 사용자가 개발자 옵션에서 켜고(`FULL`) Bluetooth를 껐다 켰다. snoop 원본은 bugreport의 `FS/data/log/bt/btsnoop_hci.log`에서 꺼냈고, G435 주소의 ACL handle(`0x3`)에서 G435가 보낸 패킷만 L2CAP PSM으로 분류했다.

| 시각 | 사용자 조작 | G435 → 폰 신호 |
|---|---|---|
| 15:33:37–15:34:36 (logcat) | 전원 짧게 4번(5초 간격) 후 3초 이상 | 짧은 누름: 없음. 길게: 원격 연결 끊김(`REMOTE_USER_TERMINATED`) = 기존 전원 끄기 |
| 15:54:40 | + | AVCTP 절대 볼륨 `0x1f` |
| 15:54:41–15:55:20 | 전원 짧게 4번(약 8초 간격) | 없음 |
| 15:55:20 | − | AVCTP 절대 볼륨 `0x17` |
| 16:00:54 | + | AVCTP 절대 볼륨 `0x2f` |
| 16:00:55–16:01:08 | 마이크 4번 | 없음 |
| 16:01:08–16:01:18 | − 후 − 여러 번, + | 볼륨 `0x27`→`0x07`→`0x0f` |

- 음소거 3초 이상(16:10:15–16:11:15, 재생 중, + 16:10:20 뒤 시험): 누를 때마다 G435가 연결을 끊었다(16:10:24, 16:10:41, 16:11:12, HCI reason `0x13` 원격 종료). 그 직후 G435가 다시 연결해 HFP 연결 명령부터 다시 보냈다(16:10:30, 16:11:15). 16:10:55–16:11:00에는 폰의 재연결 시도가 연결 직후 세 번 끊겼다. 누름 명령(AVRCP/HFP)은 없었다. 연결 해제·재연결 동작이라 소리가 몇 초~수십 초 끊기므로 제스처로 쓸 수 없다. 다른 페어링 기기(PC)로 넘어가는 동작인지는 확인하지 않았다.
- 파서 검증: 같은 snoop에서 재연결 시 G435가 보낸 HFP 명령(`AT+BRSF`, `AT+CIND`, `AT+XAPL`, `AT+IPHONEACCEV` 등)이 RFCOMM으로 잡혔다. 전원·마이크가 HFP나 AVRCP를 보냈다면 잡혔어야 한다.
- 이전 logcat 시험(15:34:11)의 HFP 1건은 `AT+IPHONEACCEV=1,1,5`(배터리 0–9 중 5 → 60%) 형식의 배터리 보고로 정정한다. 누름 신호가 아니다.
- logcat 시험(14:55, 15:33, 15:37)에서도 전원·마이크 누름에 대한 AVRCP passthrough, HFP, 볼륨, 키 이벤트가 없었다.

## 리스크/이슈

- 짧은 누름과 전원·음소거 각각의 길게 누름만 시험했다. 전원+음소거 등 동시 누름은 시험하지 않았다.
- 마이크 4번은 13초 안에 눌러 개별 시각은 없다. 그 구간 전체에 패킷이 0건이므로 결론에는 영향이 없다.
- 결과는 이 기기·펌웨어·Bluetooth 연결에 한정한다.
