## 이미 확인한 사실

- tested (2026-10-31): 무반응 시 Windows 숫자도 그대로다. + 4번 뒤 G435가 “따닥” 소리를 내며 멈췄고 Windows 값은 `0.69167`이었다. 무반응은 G435 자체 최대 도달로 설명된다. [보고서](../reports/261031-2004-08-windows-volume-max.md).
- G435 버튼은 고정 단계 값으로 Windows 볼륨을 바꾼다. 직접 키/HID·음소거 입력은 여전히 입증하지 못했다.

- tested (2026-10-31 20:06–20:07): 최소는 Windows `0.0`이며 알림음 없이 더 반응하지 않는다. PC로 85%를 만든 뒤 G435 +는 무반응, −는 `0.62521`로 되돌아간다. G435 조절 범위는 Windows 0%–69%다.

## 요구사항과 완료 기준

1. Hands-Free 전환이 다시 생기면 그 시각과 직전 사용 프로그램을 기록한다. 2026-10-31 20:09 강의 재생 중에는 재현되지 않았다.
2. 진단기 조회 주기가 실행마다 약 1–2.7초로 달라지는 원인(Hands-Free 조회 오류 추정)을 확인하고, 누름마다 기록이 필요하면 변경 콜백을 검토한다.
3. 재매핑의 신뢰성이 입증되기 전에는 완성 기능으로 판정하지 않는다.
4. 재생/일시정지 제스처([보고서](../reports/261101-2312-11-windows-play-pause-gesture.md))는 Chrome·Spotify에서 확인했다. 실사용 중 오인식과 무음 유지 10분 제한을 확인한다.
