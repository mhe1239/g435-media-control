## 목표

Bluetooth G435로 앱별 알림을 읽는 기능을 제공할 수 있는지 검토한다. 간단히 읽기는 앱 이름만, 자세히 읽기는 알림 내용을 읽는 요구다.

## 요구사항과 완료 기준

- Galaxy Wearable의 Buds 전용 기능을 G435에 그대로 적용할 수 있다고 설명하지 않는다.
- 현 기기의 기본 기능 지원 여부와 별도 NotificationListenerService/TTS 구현을 구분한다.
- 앱 선택, 읽기 수준, 알림 접근 승인, 잠금화면 민감 정보, 중복·그룹 알림 처리, Bluetooth 출력 및 다른 오디오와의 관계를 정의한다.
- 구현 작업이 승인된 범위에서 개발한 뒤 실제 알림으로 앱 선택과 두 읽기 수준을 확인한다. 아직 이 단계에 도달하지 않았다.

## 작업 요약

현재 진단 앱에는 알림 읽기 구현이 없다. 미디어 버튼 수신 성공 여부와 독립적인 요구사항이므로, 버튼 진단 실패만으로 알림 읽기도 불가능하다고 결론내리지 않는다.
